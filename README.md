# Employee Turnover Analysis with A/B Testing

**Tools:** Python (Pandas, SciPy), SQL, Power BI

# Project Overview
Analyzed workforce data to identify high-risk turnover demographics and validate key churn drivers.

# What I Did
- Cleaned and structured raw workforce datasets using Pandas to isolate high-risk turnover demographics.
- Conducted Statistical Hypothesis Testing (T-Tests & Chi-Square) to validate key churn drivers like salary gaps and overtime.
- Extracted critical demographic metrics and departmental breakdown data using advanced SQL queries.
- Built an interactive Power BI dashboard to visualize organizational turnover metrics, risk factors, and A/B test sample sizes.

# Project Structure
- `data/` - Raw and cleaned workforce data
- `src/` - Python code for cleaning & A/B testing
- `sql/` - SQL queries
- `outputs/` - Power BI dashboard (.pbix) and screenshots

# Key Insights
- Overtime and low salary are significant drivers of turnover (validated by Hypothesis Testing).
- Dashboard shows turnover by department, salary slab, and risk factors.
